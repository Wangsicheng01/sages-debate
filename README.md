# 诸神议事厅 · 多智能体辩论系统

让孔子、苏格拉底、尼采、富兰克林针对同一议题展开辩论，模拟真实的思想交锋。

## ✨ 功能

- **多智能体辩论**：四位圣贤依次立论、互相反驳、投票表决
- **流式输出**：每句话实时推送，像直播一样逐字显示
- **自定义圣贤**：输入名字和描述，自动生成角色人设
- **头像生成**：根据身份自动生成头像，点击可重新生成
- **领域识别**：自动分析议题所属领域，匹配最合适的圣贤
- **记忆库**：每位圣贤记住自己的发言，辩论更连贯
- **导出报告**：一键导出 Markdown 格式的辩论记录

## 🛠️ 技术栈

- **后端**：Python + Flask
- **模型调用**：Agnes AI API（`agnes-2.5-flash`）
- **前端**：HTML + CSS + JavaScript（原生）
- **数据存储**：本地内存 + 浏览器 localStorage

## 🚀 如何运行

### 1. 安装依赖

pip install -r requirements.txt

2. 配置 API Key
3. 
在项目根目录创建 .env 文件，写入：

AGNES_API_KEY=sk-你的密钥

获取密钥：https://platform.agnes-ai.cn

3. 启动服务

python app.py

4. 访问
  
浏览器打开 http://127.0.0.1:5000
